Xonta MAX

For developers building bots and mini-apps for MAX, the Russian national messenger that is now opening up in other countries. Official docs are Russian-only; this server answers in English.

  • Current Bot API facts with links to dev.max.ru: the new host, removed methods, limits, dated 2026 changes
  • Checks your code for old API calls, token leaks, webhook and initData mistakes, with line numbers and fixes
  • Ready bot projects in Python, TypeScript or Go, message builder and validator, Telegram formatting converter
  • Deep links and a "Send to MAX" share button for any website, no bot needed
  • Test mocks: all 19 webhook update types, signed mini-app initData, a window.WebApp emulator
  • Ad campaigns: tracking links per channel, CPM/CPA/ROAS report with confidence intervals, Russian ad-marking check
https://mcp.xonta.ru/max/mcp

Xonta Customs RU

For anyone shipping goods to Russia or the Eurasian Economic Union (Armenia, Belarus, Kazakhstan, Kyrgyzstan): suppliers, importers, logistics and marketplace sellers. The agent gets the tools of a customs broker.

  • Parses a supplier invoice or packing list (Chinese, English or Russian headers) and checks the arithmetic
  • Finds EAEU TN VED (HS) codes from a product description, with duty rates
  • Calculates duty (ad valorem, specific, combined), antidumping, excise, VAT 22% / 10% and the 2026 customs fee in rubles
  • Car recycling fee, antidumping measures by country, EEC classification rulings, Central Bank exchange rates
  • Every number comes with its source, and the server says plainly when it doesn't know
https://mcp.xonta.ru/customs/mcp

Xonta Документы

For agents that prepare Russian business paperwork: invoices and acts in PDF and Word, checks of Russian company details (INN, KPP, OGRN, BIC), amounts in words, name declension, the Russian working-day calendar, document recognition. The site is in Russian.

Connect

Add the address to Claude, Cursor, Windsurf or any client that supports remote MCP servers:

{
  "mcpServers": {
    "xonta-max": { "url": "https://mcp.xonta.ru/max/mcp" },
    "xonta-customs": { "url": "https://mcp.xonta.ru/customs/mcp" }
  }
}

Or run them locally from PyPI, for example uvx xonta-max-mcp. All three are also in the official MCP registry and on Glama.

Why the servers have passports

When you connect a tool server, you trust that it is what it says it is and that its tools haven't quietly changed. Xonta MAX and Xonta Customs are registered with the Xonta orchestrator, which proved control of the domain and signed a scan of the tool list. The passport page checks those signatures in your browser, so you don't have to take our word for it.

Get a passport for your own agent or MCP server The Xonta orchestrator checks agents, issues W3C Verifiable Credentials anyone can verify, and examines how far an agent can be trusted with real actions. Registration is free.
